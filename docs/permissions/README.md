# Permission requests

Range maps and bulk data from these groups cannot go on the public site without a written yes. Each draft below is ready to send. Log the date sent and every reply in the table, and save replies as `replies/<source>-<date>.md`.

| Source | Draft | Gates | Sent | Reply |
|---|---|---|---|---|

| BirdLife Data Zone | [birdlife.md](birdlife.md) | Expert bird range maps (Phase 2) | | |
| Reptile Database | [reptile-database.md](reptile-database.md) | Distribution text and checklist fields on reptile pages (Phase 2) | | |
| AquaMaps | [aquamaps.md](aquamaps.md) | Bulk marine and fish range data (Phase 3) | | |
| AmphibiaWeb | [amphibiaweb.md](amphibiaweb.md) | Amphibian taxonomy service and links (Phase 3) | | |

Rules of thumb:

- Send IUCN and BirdLife first. Nobody has documented how quickly they answer hobby projects.
- Always say the site is free, non-commercial, open source and carries no ads. Those facts decide most of these.
- Promise attribution and a link on every map, and offer to show them the map before launch.
- A yes that only covers viewing, not derived tiles, is still a no for the map. Ask specifically about simplified hexagon derivatives.
